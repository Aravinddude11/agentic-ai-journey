# 🤖 Agentic AI Journey

> Learning Agentic AI from scratch, one day at a time, and documenting everything in public.

I'm learning how to build AI agents: programs that can **plan, use tools, remember things, check their own work, and finish a task** without me guiding every step. This repo is my learning diary. Every day I add notes, diagrams, and code for what I learned.

If you are a beginner too, feel free to follow along, fork it, or open an issue with suggestions.

---

## 🎯 Goal

Go from **"I can write a good prompt"** to **"I can build an agent that does real work."**

## 🗺️ How I'm Learning

I'm following a free 6-week roadmap, one course per week. Full details are in [roadmap.md](./roadmap.md).

| Week | Topic | What I'll build |
|------|-------|-----------------|
| 1 | Foundations: the agent loop | Understand how an agent thinks and acts |
| 2 | Tools: function calling | A small tool-using agent |
| 3 | Memory | Add memory to that agent |
| 4 | Multi-agent teams | A team of 2–3 agents |
| 5 | Evaluation | At least one test for my agent team |
| 6 | Production | Rebuild the agent with production-ready patterns |

## 📝 How Each Day Is Documented

Every day folder follows the same simple template:

1. **Today I learned**: one line summary
2. **Key concepts**: the main ideas in plain words
3. **Diagram**: a picture of how it works
4. **Code**: a small example I actually ran
5. **Questions I still have**: things I need to explore next

Keeping the same format every day makes it quick to write and easy to read later.
